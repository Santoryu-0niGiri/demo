# Git Branching and Feature Flag Demo

This repository demonstrates a basic Git workflow using a feature branch, pull request, code review, and merge into `main`.

## Project Purpose

The project is intentionally small so that the Git workflow can be observed clearly.

## Workflow

1. Create the repository.
2. Create `feature/new-feature`.
3. Update this README.
4. Commit and push the feature branch.
5. Open a pull request to `main`.
6. Review the pull request and request a change.
7. Apply the requested change.
8. Merge the pull request into `main`.

The next stage demonstrates trunk-based development concepts with a configuration-based feature flag.
